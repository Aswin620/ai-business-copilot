# AI Business Operations Copilot

An AI-powered business operations assistant capable of understanding
natural language requests, retrieving company knowledge, executing
business tools, and requesting human approval for sensitive actions.

## Project Goals

- Natural language business assistance
- Retrieval-Augmented Generation
- Tool calling
- Workflow automation
- Human-in-the-loop approval
- Conversational memory
- Enterprise integrations

## Planned Technology Stack

- React
- Tailwind CSS
- FastAPI
- PostgreSQL
- pgvector
- Redis
- Llama
- Ollama
- LangGraph
- Docker
- Kubernetes
- GitHub Actions
- Langfuse
